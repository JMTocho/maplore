# Package index

## Components

Add these to a map created with
[`mapgl::maplibre()`](https://walker-data.com/mapgl/reference/maplibre.html)
or
[`mapgl::mapboxgl()`](https://walker-data.com/mapgl/reference/mapboxgl.html).

- [`add_view_summary()`](https://jmtocho.github.io/maplore/reference/add_view_summary.md)
  : Add an "in this view" summary panel to a map
- [`add_view_ranking()`](https://jmtocho.github.io/maplore/reference/add_view_ranking.md)
  : Add a ranking of the features in view
- [`add_context_tooltip()`](https://jmtocho.github.io/maplore/reference/add_context_tooltip.md)
  : Add a tooltip that puts each value in context
- [`add_feature_search()`](https://jmtocho.github.io/maplore/reference/add_feature_search.md)
  : Add a search box over the layer's own features
