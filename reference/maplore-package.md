# maplore: Context Components that Help Readers Understand 'mapgl' Maps

Adds components to 'mapgl' maps ('MapLibre GL JS' and 'Mapbox GL JS')
that put what the reader sees in context: a live summary of the features
in view compared with the whole map, a ranking of the features in view,
a tooltip that shows where each value stands among all of them, a search
box over the map's own data, notes on the data and its sources, and an
animation that lifts the map's shapes into a grid sorted by their
values. Everything runs in the browser, so the components work in static
HTML, 'R Markdown' and 'Quarto' documents without a 'Shiny' server.
